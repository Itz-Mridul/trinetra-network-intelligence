# Required Arduino Libraries for esp32_probe.ino
# Install all of these via Arduino IDE → Library Manager

# 1. PubSubClient (Nick O'Leary)
#    Version: >= 2.8
#    Install: Arduino IDE → Sketch → Include Library → Manage Libraries → Search "PubSubClient"
#    GitHub:  https://github.com/knolleary/pubsubclient

# 2. ESP32Ping (Optional / Not needed)
#    esp32_probe.ino now uses native TCP handshake round-trip latency (RFC 3550 jitter)
#    via standard WiFiClient, requiring no external ping library.

# 3. Arduino ESP32 Board Support
#    Install: Arduino IDE → Preferences → Additional Board URLs:
#    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
#    Then: Tools → Board → Board Manager → Search "esp32" → Install esp32 by Espressif
